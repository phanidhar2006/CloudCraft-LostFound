AWS ARCHITECTURE

Built for the cloud

CloudCraft uses AWS services to separate application hosting, image storage and data.

Amazon EC2 Hosts the Flask web application.
Amazon S3 Stores uploaded item photographs.
Amazon DynamoDB Stores structured lost-and-found records.
IAM Controls access to AWS resources.
Presigned URLs Provide temporary secure image access.
Moderation Workflow Keeps unreviewed reports hidden.
